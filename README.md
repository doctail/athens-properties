# Athens Properties

Faceless YouTube channel studio. Start from `studio/CHANNEL.md`; agents are in `.claude/agents/`, the pipeline in `.claude/skills/video-pipeline/`.

## MCP servers (`.mcp.json`)

- **nodum** — Nodum knowledge base (copy of the channel memory in the `Canale YT` folder). The token is a network secret on the cloud environment; the header in `.mcp.json` is only a placeholder.

Images are generated by the owner in Google Flow from the prompt files in each episode folder.
