# Focus Flow Lab — production files

**Come si fa un video:** Nodum `CH Focus/RECIPE Focus` (anche riassunto qui sotto). **Cosa fare dopo:** Nodum `CH Focus/BACKLOG Focus`.

Ogni video ha la sua cartella con `make.sh` (genera il video), `metadata.md` (titolo, descrizione, tag) e `thumb.jpg`. Il file `video.mp4` NON è nel repo (12 h ≈ 0,8 GB, oltre il limite di GitHub): si genera con `make.sh`.
