# EP04 — fact check and sources

Status: DRAFT v1. Confidence tags as in RULES (#8). **How these were checked:** on 2026-11-16 each study below was looked up with free web search (abstract / press summary / reference page). Full papers were NOT read. Column "Checked" says what was actually seen. Anything marked "wording check" must be compared with the paper text before upload. No paid tool was used.

Scope note (important for every anthropology claim): we have almost no direct evidence of privacy behavior in the Paleolithic. Archaeology shows shelters and camp layouts; behavior is inferred from (a) living foragers and (b) cross-cultural studies. Both are analogies, not proof. The script says so in the THE CAMP section and flags each inference in the line itself.
