# EP05 — fact check and sources

Status: DRAFT v1 (2026-11-20). Confidence tags as in RULES (#8). **How these were checked:** on 2026-11-20 each claim was looked up with free web search (WebSearch result summaries: abstracts, press releases, reference pages). Full papers were NOT read, and the direct page fetches (Leiden, earth.com, French Ministry of Culture) failed because those hosts are outside the session's allowed network, so the Mezhyrich and Lascaux items rest on search summaries only. Column "Checked" says what was actually seen. "ABSTRACT/SUMMARY ONLY" means the narrated wording must be compared with the paper before upload ("wording check"). No paid tool was used.

Scope note: the Ice Age is well documented by climate science (ice cores, sediments, sea level) but human daily life at 20,000 years ago is inferred from a thin archaeological record: a few sites (Mezhyrich, Lascaux, Pavlov, Kostenki), bone and stone tools, and analogy. The script says "most likely", "suggests", "still debated" in each line that depends on interpretation. Dave's camp is a composite in the style of Mezhyrich (Ukraine), not a single real camp.

## Production notes
- Use "most likely", "suggests", "may", "by one estimate", "still debated" for everything inferred. Never narrate Ice Age behavior as fact when the only evidence is an animal bone pattern or a news summary.
- Dave's camp is a composite (Mezhyrich-style dwellings, Lascaux lamp, Czech skinning marks, French spear-throwers). The images show it as one camp for storytelling; the script never says all of this happened at one site. Keep it that way in the description.
- No cave-art claims in this script (dating of Lascaux paintings and the 17,000 figure for the lamp are different questions). The Lascaux line is about the lamp only.
- "Ice Age" in titles and thumbnail text is fine; the narration corrects the myth, so avoid titles that imply the whole planet was frozen.
