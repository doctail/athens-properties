# EP01 — Google Flow image prompts (96 images, 4 runs × 24)

## How to use
1. Download the Dave model sheet in full resolution: https://www.canva.com/M/MAHaajzXE40 → attach it in Flow as the **reference image** in EVERY run.
2. For each run, paste the **HEADER** block below, then the 24 numbered prompts of that run, as one single text.
3. Aspect ratio: **16:9**. Download all images of the run and keep Flow's order.
4. Upload them to the repo in `studio/episodes/ep01-every-era/images/run1/` … `run4/` (GitHub web → branch `claude/cool-maxwell-9j1fc7` → Add file → Upload files). Renaming is optional: I match images to numbers visually.

## HEADER (paste at the top of every run)
```
Generate 24 separate images, one for each numbered prompt below, in the same order.
STYLE FOR ALL IMAGES: flat 2D vector cartoon, thick dark-brown outlines, no gradients, simple clean shapes, warm earthy palette (mustard yellow, terracotta, olive green, sand, deep blue), 16:9 landscape. NO text, NO letters, NO numbers, NO watermarks, NO captions inside the images.
DAVE = the character in the reference image: man in his early 30s, slightly chubby, messy brown hair, short stubble, big expressive eyes, mustard-yellow hoodie, blue jeans, white sneakers, often holding a smartphone. Keep Dave IDENTICAL in every image (same face, hair, hoodie colour, proportions).
```
